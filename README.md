# SecureScan – Android Document Scanner & PDF Manager

SecureScan is an Android application built with Kotlin and Jetpack Compose for secure document scanning, PDF management, OCR, digital signatures and QR code safety analysis.

## Features

- Document scanning and PDF generation
- PDF password protection
- PDF compression and optimization
- Merge, split and extract PDF pages
- PDF rotation, cropping and resizing
- PDF editing and redaction
- OCR-based text extraction
- Digital signature addition and extraction
- QR code scanning and URL safety analysis
- PDF and image file management
- User authentication

## Technology Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Hilt
- SQLite / Firebase components
- ZXing
- ML Kit
- PDFBox

## Project Structure

- `app/src/main/java/` – Application source code
- `app/src/main/res/` – Android resources
- `gradle/` – Gradle wrapper configuration

## Build Instructions

1. Clone this repository.
2. Open the project in Android Studio.
3. Configure your own Firebase settings if required.
4. Sync Gradle.
5. Build and run the application on an Android device.
